# I18N Contract

接口字段与错误 Contract 见 [API.md](API.md)；前端按流程的调用与降级处理见 [FRONTEND_INTEGRATION.md](FRONTEND_INTEGRATION.md)。

本文记录前后端共享的多语言约定：哪些响应字段是 `LocalizedText`、哪些字段是稳定枚举键、前端显示时的回退顺序、语言扩展方式和 attribution 处理。`LocalizedText` 定义在 `@nikuman-yummy/shared` 的 `localization.ts`，形状为 `{ ja: string; en?: string; zhHans?: string }`，`ja` 必填、其余可选。

## 1. `LocalizedText` 字段

以下响应字段是 `LocalizedText`：

- **区市町村名**（`/api/municipalities`、`/api/location/municipality` 的 `name` / `municipalityName`）：三语齐备。英文为官方表记（23 个特别区均为「X City」），中文为简体标准译名。
- **设施名**（`/api/facilities/search` 的 `facilities[].name`）：**只有 `ja`**。设施名来自官方开放数据的原文，按诚实原则不做机器翻译。前端直接显示日文设施名，便于用户在现场对照标识牌。
- **警报标题**（`/api/alerts` 的 `alerts[].title`）：JMA 警报为 `ja`，仅当气象庁 feed 提供英文震源名时附 `en`，不生成 `zhHans`——服务端不翻译安全相关的官方措辞；演示警报固定为三语（强制带 (デモ)/(demo)/(演示) 后缀）。
- **地区内残留地区名**（`stayPutZones[].name`）：**只有 `ja`**，是官方指定的专有地名，不翻译。

## 2. 稳定枚举键

以下字段是稳定枚举键，不随语言变化，前端通过 `@nikuman-yummy/shared` 导出的 `ENUM_LABELS` 渲染显示文案：

- `facilityType`：`evacuation_area` / `evacuation_shelter`
- `dataStatus`：`confirmed` / `not_realtime` / `unknown` / `unavailable`（PRD §6.2，禁止把 `not_realtime` 或 `unknown` 显示为“已开放”）
- `userState`：`safe` / `uncertain` / `danger` / `need_help`
- `riskAnswer`：`yes` / `no` / `uncertain`
- `environment`：`indoor` / `outdoor` / `transit`
- `stayPutStatus`：`in_zone` / `outside_zone` / `undetermined`
- `disasterType`：`earthquake` / `tsunami` / `flood` / `landslide` / `volcanic` / `fire`
- `accessibility`：`elevator_or_ground_floor_space` / `slope` / `braille_blocks` / `wheelchair_accessible_toilet`；`other:<free text>` 形式的值原样透传冒号后的日文自由文本，不做翻译。

当前语言包版本为 `I18N_LABELS_VERSION = "i18n-draft.1"`，是**工程草案**：PRD FR-02 要求安全关键文案必须来自审核过的固定语言包，审核通过前不得把这些标签当作定稿文案；审核通过时需提升版本号并记录审核。

## 3. 显示回退顺序

单个 `LocalizedText` 字段缺失请求语言时，前端按以下规则回退：

```
请求语言 → en → ja
```

`ja` 始终存在，是最终保底。**产品的默认回退语言是英文还是日语仍是 PRD 待确认事项 TBD-03**，因此存在两种可能的完整顺序：

```
ja 请求：ja
en 请求：en → ja
zhHans 请求：zhHans → en → ja   （方案 A：默认回退英文）
zhHans 请求：zhHans → ja        （方案 B：默认回退日文）
```

前端必须把默认回退语言实现为**一个可切换的常量**，TBD-03 确定后只改这一处，不得在组件里散落硬编码顺序。

## 4. 语言扩展

新增一种语言只需两步：

1. 在 `LocalizedText` 上增加一个可选键（例如 `zhHant?: string`）；
2. 在语言包中为各条目补充对应文案。

API 响应形状不变，后端无需改动。

## 5. Attribution 不翻译

`sources[].attribution` 等署名字符串是 CC BY 来源按 publisher 要求原样返回的，**必须逐项原样显示，不得翻译、不得合并**。多语言处理只适用于上面第 1、2 节列出的字段。
